# MiSTerEmby Downloader database

This branch is generated by the release workflow and holds the MiSTer Downloader database (`db.json`), plus the files each release installs, under `files/<version>/`. Don't edit it by hand.

To use it, copy [`downloader_misteremby.ini`](https://github.com/freemchr/MiSTerEmby/blob/main/downloader_misteremby.ini) to `/media/fat/` on your MiSTer, then run the downloader. See the [main README](https://github.com/freemchr/MiSTerEmby#installing-and-updating-with-mister-downloader).
